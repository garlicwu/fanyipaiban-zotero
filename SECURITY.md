# Security Policy

## Reporting a vulnerability

Please do not publish API keys, translated documents, or account details in a public issue. Report security concerns to `124005421@qq.com` with the subject `FanyiPaiban Zotero Security`.

## Credential handling

The plugin stores API keys in Zotero's local credential store. It never adds an API key to URLs, Zotero item metadata, pending task JSON, or normal debug messages.

## Supported versions

Security fixes are provided for the latest released plugin version.
